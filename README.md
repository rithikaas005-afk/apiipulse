# API Pulse – API Health & Performance Monitor

API Pulse is a premium, minimal, and high-performance API monitoring dashboard built with a Flask backend and a modern vanilla HTML/CSS/JS frontend.

## Architecture

- **Backend**: Python, Flask, Requests.
- **Frontend**: Single page dashboard with dynamic JSON inspection, uptime statistics, and performance history graphs using Chart.js.
- **Port**: Runs on `http://localhost:5002`

## Installation & Running

1. Install requirements:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the application:
   ```bash
   python app.py
   ```

3. Open `http://localhost:5002` in your browser.
